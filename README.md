# candiddevelopment.com

Ryan Marshall's personal page: one static page, no build step, served by GitHub Pages from `main`.

- `index.html`: the page
- `style.css`: all styling (light and dark mode, phone layout)
- `images/profile.jpg`: portrait
- `CNAME`: custom domain for GitHub Pages

The text is carried over from the 2015 version of the site. The design is new.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
